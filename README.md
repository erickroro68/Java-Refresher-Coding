Java Refresher Coding Repository:

This repository is a collection of small Java projects, practice exercises, and learning experiments created as part of my ongoing journey to strengthen my Java fundamentals. Each folder represents a standalone mini‑project or coding challenge, ranging from simple algorithm warm‑ups to more structured applications. The goal of this repo is to track progress, stay consistent with hands‑on practice, and build a foundation for future software engineering projects.

This repo is intentionally simple and beginner‑friendly. Every project is written in plain Java, using basic tools and standard project structures. Some folders include Maven projects, while others are pure .java files organized by topic. Over time, this repository will grow into a personal reference library of Java concepts, patterns, and problem‑solving techniques.

📁 Repository Structure::
                                                                          
Below is a high‑level overview of each folder and what it contains:

Challenge_MEAN_MODE/
A small challenge focused on calculating the mean and mode of a dataset. This folder contains Java implementations of basic statistical operations and is useful for practicing loops, arrays, and logic building.

ENcryptionLOCKER/
A simple encryption/decryption experiment. This project explores string manipulation, character shifting, and basic algorithm design. It’s a good example of how to break down a problem into smaller steps.

FizzBuzz/
A classic beginner problem used to practice conditionals and loops. This folder includes multiple variations of the FizzBuzz solution, showing different ways to approach the same logic.

Leetcode_Folder_Problems/
A collection of LeetCode practice problems. Each subfolder contains one problem and its Java solution. This section is focused on improving algorithmic thinking, data structures, and interview‑style problem solving.

PythonCode/
Although this repo is mainly Java, this folder contains a few Python scripts used for quick experiments or comparisons. These files are simple and not tied to the Java projects.

football/
A small Java program simulating football team data, game generation, and basic object‑oriented design. This folder includes classes like Team, teamLoader, and gameGenerator, making it a good example of OOP fundamentals.

privdeals/
A Maven‑based Java project with a simple structure under src/main/java. It includes classes for handling transactions and basic logic for a small console‑based application. This folder also contains a taxes/ submodule with its own Main.java.

🛠️ How to Run the Projects
Most folders contain plain .java files and can be run using:

Code
javac FileName.java
java FileName
For Maven projects (like privdeals/):

Code
mvn clean install
mvn exec:java
You can also open the entire repository in an IDE such as:

IntelliJ IDEA

VS Code with Java extensions

Eclipse

Each project is self‑contained, so you can open folders individually or run them all from the root workspace.
